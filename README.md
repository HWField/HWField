## Featured projects

### Epidemic Simulation | Computer Science NEA

**AQA A Level Computer Science NEA: 100%**

[Source code](https://github.com/HWField/NEAComputerScience-ALevel-) · [Project report](https://github.com/HWField/NEAComputerScienceReport-ALevel-)

A full-stack simulation platform modelling the spread of airborne infectious diseases through agent populations in real-world locations.

The simulation incorporates transmission rates, recovery times and social interactions. A Vue frontend presents live simulation data through interactive charts, allowing users to explore the results and behaviour of the model.

The project brought together simulation logic, backend development, database integration and interactive data visualisation.

**Technologies:** C# / .NET, Entity Framework, PostgreSQL, Vue 3, Pinia and Tailwind CSS.

### NeuroNote | Extended Project Qualification

**OCR EPQ: 100%**

[Source code](https://github.com/HWField/NeuroNote-EPQ-) · [Project report](https://github.com/HWField/NeuroNoteReport-EPQ-)

A full-stack visual note-taking Progressive Web App (PWA), developed as the software artefact for my EPQ investigation into the science behind student note-taking methods.

NeuroNote brings that research into an interactive environment for creating and exploring notes visually. The project combined independent research with application design and development, connecting an educational question with a practical software implementation.

**Technologies:** Vue 3, TypeScript, Python / Flask, PostgreSQL, Cytoscape.js and Socket.IO.
